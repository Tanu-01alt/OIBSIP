# 📊 Exploratory Data Analysis (EDA) on Retail Sales Data

## 📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on an Online Retail Sales dataset using Python. The objective is to explore retail transaction data, identify sales trends, understand customer purchasing behavior, and generate meaningful business insights through data analysis and visualization.

This project is completed as part of the **Oasis Infobyte Internship (OIBSIP) – Data Analytics Task 1**.

## 🎯 Project Objectives

- Understand and explore the retail sales dataset.
- Perform data cleaning and preprocessing.
- Identify and handle missing values and duplicate records.
- Analyze sales trends and customer purchasing patterns.
- Identify top-selling products.
- Perform country-wise sales analysis.
- Create visualizations to represent important findings.
- Extract meaningful insights from retail data.

## 📂 Dataset Information

**Dataset Name:** OnlineRetail.csv

The dataset contains online retail transaction records.

### Dataset Columns

| Column Name | Description |
|---|---|
| InvoiceNo | Invoice number of the transaction |
| StockCode | Unique product code |
| Description | Product description |
| Quantity | Number of products purchased |
| InvoiceDate | Date and time of transaction |
| UnitPrice | Price per unit |
| CustomerID | Unique customer identification number |
| Country | Customer's country |

## ⚙️ Installation & Setup

### Step 1: Install Python

Download and install Python from:

https://www.python.org/downloads/

### Step 2: Install VS Code

Download Visual Studio Code:

https://code.visualstudio.com/

### Step 3: Install Required Libraries

Open Command Prompt or the VS Code terminal and execute:

```bash
pip install pandas numpy matplotlib seaborn jupyterlab
```

### Step 4: Launch JupyterLab

Open Command Prompt and execute:

```bash
python -m jupyterlab
```

Alternatively, you can launch JupyterLab using:

```bash
jupyter lab
```

JupyterLab will open in your default web browser. You can work with your `.ipynb` notebook files in this environment.

Step 5: Run the Project

1. Open your project folder in VS Code.
2. Launch JupyterLab using the commands above.
3. Open the project notebook.
4. Make sure `OnlineRetail.csv` is available in the correct directory.
5. Run the notebook cells sequentially to perform the analysis.
